A deterministic, local-first work ledger for humans, tools, and agents. It records requests, derives versioned tasks, and leases ready work — without a remote service.

What it does — and refuses to do

aiq doesaiq does not
Keep an append-only local journalCall models or execute task work
Turn messages into atomic task changesSync state between machines
Derive readiness from dependenciesRequire a server or account
Fence concurrent work with leasesPut runtime state in Git

Install

Python 3.11–3.14 on Linux or macOS; runtime dependencies come from the standard library alone.

pipx install 'aiq-workqueue @ git+https://github.com/spincyc/aiq.git@main'
aiq --version

aiq never updates itself. Refresh explicitly with pipx install --force, then run aiq reconcile --user to confirm hooks and journal state still match the installation.

Sixty seconds of ledger

Inside any Git repository:

aiq ingest --message "Create the first reusable task"
aiq inbox list            # exact content stays private until claimed
aiq queue peek            # read-only preview of ready work
aiq queue next --owner me # lease the highest-priority ready task
aiq status                # bounded snapshot: messages, tasks, claims
aiq journal check         # verify storage and semantic history

Discovery is part of the contract: aiq capability list names every operation in one compact table, and aiq capability show <id> loads a single versioned contract — an agent never carries the full manual in context.
