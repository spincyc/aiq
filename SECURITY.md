# Security policy

## Supported versions

Until AIQ reaches 1.0, only the latest tagged release receives security fixes.

## Reporting a vulnerability

Do not report vulnerabilities in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/spincyc/aiq/security/advisories/new).

Include the affected version, impact, and a minimal reproduction when
possible. Remove message content, journal databases, credentials, personal
paths, and other sensitive data unless a specific item is essential to the
report.

AIQ stores exact messages and derived work state locally. Reports involving
unexpected disclosure, unsafe path handling, journal-integrity bypasses, or
integration changes outside AIQ's declared ownership are especially useful.
